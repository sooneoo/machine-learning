# 002-perceptron

Druhý experiment zkoumá model jediného neuronu s libovolným počtem
vstupů a odpovídajících vah. Zvolenou aktivační funkcí je sigmoida.
První úlohou je logická funkce AND se ztrátou MSE a dávkovým
učením BGD. Po učení následuje vyhodnocení oddělené validační
množiny. Podrobnosti dat a rozhraní ještě společně určíme.
