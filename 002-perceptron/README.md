# 002-perceptron

Druhý experiment zkoumá model jediného neuronu navazující na lineární
regresi. Zvolenou aktivační funkcí je sigmoida, která vytváří
monotónní křivku tvaru S. Data a postup ověření určíme ve společném
návrhu před zahájením implementace.
