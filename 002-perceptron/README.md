# 002-perceptron

Druhý experiment zkoumá model jediného neuronu s libovolným počtem
vstupů a odpovídajících vah. Zvolenou aktivační funkcí je sigmoida.
První úlohou je logická funkce AND se ztrátou MSE. Postup učení
a ověření určíme ve společném návrhu před zahájením implementace.
